## 1. 결론과 범위

누적 원천에서 오늘 매칭된 유형을 연구한 결과 네 고정감시 종목과 일반 종목에 추가 기회가 있다. 삼성의 작은 눌림은 성공 사례 자체가 없었던 것이 아니다. 그러나 이번 고정 유형 조합에서 **기존 누적 도달률을 유지하면서 오늘의 추가 성공까지 확인된 삼성 정규장 후보는 없었다.** 미확정 20건을 성공으로 바꾸지 않았다.

- 기계 판정 cutoff: **2026-10-07 15:17:07 KST**. 시장 가격 cutoff: SOR REGULAR **15:20:00**, PRE **08:49:59**. 종일 최종 결산이 아니다.
- 연구 기준 정책: bundle `7c500126d082c4ef866ef0b74eb4012141b37902ab52e6463bcb0b7bd6b7b2da`, family `615093a91146d391842c9a3d4492537139469224436b05a946109a9bb00e5b50`. 오늘 실제 판정은 당시 여러 bundle의 증거를 그대로 구분한다. 진행 중인 다른 세션의 신규 구현/선택 결과를 이 과거 판정에 소급하지 않는다.

## 4. 누적 연구 방법과 범위

보유 native 시장 원천 날짜는 **9/21·22·23·28·29·30, 10/2·6·7의 9개 날짜**다. 오늘만 따로 최적화한 정책으로 제시하지 않고 해당 누적 모집단에서 비교했다. 이번 가설 계산은 SOR PRE/REGULAR 18개 partition, **6,046,238개 관측 행과 1,045,688개 첫 반전**을 사용했다. 9/21 등의 exact source item 결손 행은 경계로 유지하며 유효 표본으로 승격하지 않았다. 정규장 과거 검증 cache를 재사용하고 오늘 shard 전체를 한 번 고정 정규화했다. kernel SHA `17b73fbd524814faa53895148364758716aac406ca41761768cb69d430178030`은 이전 검증본과 일치한다.

오늘 native source 전체에는 KRX/NXT/SOR가 있으나 **이번 패턴 성능 표는 SOR 정규장**이다. NXT 전용 PRE 실거래 판정과 SOR PRE 탐색 성능을 합치지 않았다. AFTER는 오늘 비교 성숙 자료가 부족하여 성능 주장을 하지 않는다. PRE 보조 결과는 별도 JSON에 있으며 오늘 PRE의 완성 분봉 사용도 08:49:59까지로 제한된 보수적 관측 결과다. 이후 세션 가격까지 사용한 PRE 전체 30분 비교와 NXT 경로 재생은 별도 대상이다.

유형 축은 일반 종목의 가격대(<2만/2만~10만/10만 이상), 해당 종목의 세션 첫 유효 관측가 대비 등락(±0.4%), 직전 60초 수익률(음수/0~0.2%/0.2% 이상), 최근/직전 30초 고저 구조(상승/하락/혼합), DD5 5구간이다. 세션 흐름은 **외부 시장 지수**가 아니다. 필터는 ANY·spread≤0.1%·volume≥1·반등폭≤0.3%·직전 하락폭≤0.4%·VWAP60 이상이다. 알려지지 않은 값은 중립/0으로 채우지 않았다.

관측 가능한 유형×필터 **6,882조합**을 탐색했고, 오늘 매칭되며 기존 밖의 진입점이 있는 2,660조합을 비교했다. 원천을 본 뒤 가설/조합을 선택한 **동일 누적 자료의 탐색 결과**다. 미래 성과나 새로운 날짜의 독립 검증 결과가 아니다. 이를 이유로 별도의 최소 표본/일수·holdout·EV·기존 성공 보존 탈락 문턱을 추가하지 않았다.

라벨은 각 실행 가능 ask에서 새로 시작하는 30분, 비용 가정 0.23%를 한 번 반영한 +0.4% 목표/soft -3% 선도달이다. `FAIL_TIMEOUT`은 30분 내 목표 미도달이며 실제 매매 손실액이 아니다. 10분 이후 기존 가격/완성 분봉도 사용한다. 원천이 끊겨 선후관계나 30분을 입증하지 못하면 `UNRESOLVED`를 유지한다. 오늘 정규장 최초 반전 114,206개 중 미확정 원인은 path end 88,789·진입 호가 결손 973개다. path end에는 연속 경로 단절과 관측 종료가 함께 있으므로 전부 시장 미상승이나 네트워크 장애라고 부르지 않는다.

합집합은 `(day, market, symbol, source index)`별로 한 번 센다. 삼성 현재 shallow의 실제 확인점도 기준 정책 집합에 포함했다. 아래 추가 WIN은 실주문/독립 거래 수가 아니며 동일 상승 구간에 모일 수 있다. `distinct_target_clocks`도 독립 통계 표본수의 보장은 아니다.

## 6. 제출 기회 수를 더 우선한 대안

두 번째 비교는 오늘 매칭되는 수가 많은 후보부터 합치되 **최초 기준 정책보다 누적 도달률이 낮아지지 않는지** 확인했다. 후보를 하나 추가할 때마다 새 최고 도달률을 계속 보존하는 제한을 쓰지 않았다. 두 비교 모두 greedy 탐색이므로 가능한 모든 조합 중 최대 기회 수를 입증한 것은 아니다.

| 종목군 | 도달률 우선 조합 | 기회 수 우선 조합 | 오늘 추가 WIN/실패/미확정 변화 |
|---|---:|---:|---|
| 주성 | 532/568 = 93.66% | 1,013/1,383 = 73.25% (기준 67.02%) | 459/5/790 → **940/339/2,886** |
| 일반 | 34,128/41,288 = 82.66% | 35,593/43,409 = 81.9945% (기준 81.9918%) | 24/9/266 → **50/21/434** |

다른 네 종목의 합집합은 같았다. 일반 종목 기회 수 우선 조합의 누적 개선은 **약 0.0027%p**에 불과하다. 오늘만의 추가 확정 도달률은 도달률 우선 조합도 24/33=72.73%, 기회 수 우선 조합은 50/71=70.42%다. 누적 이점이 오늘 모든 유형에서 같은 성과로 나타나지는 않았다. 두 결과를 숨기지 않고 [기회 확대 비교](../../tmp/main-enter-pass-opportunity-research-20261007/coverage-result.json)에 함께 보존한다.

## 7. 삼성: 성공은 존재하지만 작은 낙폭 자체로는 분리가 부족

오늘 삼성 SOR 정규장 첫 반전 50,739개 중 WIN 1,355·30분 미도달 8,354·미확정 41,030개였다. DD5<0.4%만 보면 WIN **1,208**, 30분 미도달 4,816, 미확정 34,798이다. 여기에 60초 느린 상승(0~0.2%)을 추가하면 WIN 205·미도달 3,767·미확정 22,871이다. 작은 눌림 후 성공은 존재하지만 이 두 조건만으로 선별하면 확정 분모 도달률이 각각 20.05%와 5.16%에 머문다.

이번 유형 중 누적 기준을 유지한 두 추가 분기는 과거 WIN 31개와 오늘 미확정 20개뿐이다. 오늘의 추가 WIN이 있는 유형 중 가장 높은 단독 추가 합집합도 47/51=92.16%로 기준 45/46보다 낮았다. 그러므로 추가 삼성 후보를 해결 완료로 등록하거나 오늘 미확정을 미상승/성공으로 처리하지 않는다.

삼성의 다음 수동 가설은 **첫 반전의 단면 값보다 저점 재시험 뒤 회복, 고점 재돌파, 호가/체결 방향 전환의 지속 경로**다. 동일 원천에서 확인 시점을 이동하고 새 ask와 30분을 다시 계산해야 한다. 현재의 추가 확인 5초/저점 재접촉 만료와 비교하며, 최초 목표 도달을 알고 역으로 진입시점을 고르는 방식은 사용하지 않는다.

## 8. 인계와 검증

1. **정책 후보 인계:** 두산/HPSP/알테오젠/주성 및 일반 유형의 고정 정의·원천 hash·누적/오늘/미확정·겹침 결과를 등록 후보 구현 세션에 전달할 수 있도록 두 JSON을 보존했다. 수동 연구 정의를 장후가 새로 탐색하는 범위로 확대하지 않는다. 이미 계획된 S1/S2/D1/H1/A1/J1/G1~4 전체와의 최종 공동 조합은 해당 세션의 등록 manifest로 다시 비교해야 한다. 이번 성능 기준은 위 frozen 현 정책이며 아직 활성화되지 않은 후보를 현 정책으로 계산하지 않았다.
2. **기계→보조 전달:** 주성 exact 두 ID를 대상으로 claim 읽기 전 대기 4.32/2.45초와 읽기 이후 provider 직전 검증 구간을 줄이는 설계를 검토한다. 현재 FIRST가 바뀐 경우 보존 기간만 늘리지 않고 별도 지속 확인 신호로 검증한다.
3. **일반 종목 범위:** Main 7건·probe ENTER 9건의 admission/평가 연결을 별도 확인한다. 연구상 추가 원천 진입점이 곧 실제 제출 가능 수가 되지 않도록 한다.
4. **삼성 추가 연구:** 위 경로 가설을 누적 원천으로 검증한다. 추가 API 원천 수집 요구를 만들지 않는다.
5. **PASS 이후 후단:** HPSP 두 attempt의 자금 원천·수량 계획·최종 차단은 별도 후속 과제다. 보조 prompt 조정으로 후단 계약을 우회하지 않는다.

자체 리뷰에서 Main/probe 분모 혼동, 구형 rejection 시계 사용, Samsung 등록 확인점의 baseline 누락, 합집합 중복, 미확정의 실패 처리, greedy 중간 최고값을 유일 수용 기준으로 사용하는 문제를 점검했다. 현재 정책 확인점 중첩의 epoch/라벨 동일성 assertion, 두 가지 합집합 목적, 명시적 null 통계를 반영했다. 대규모 반복 지표 계산은 source 재생 cache를 보존한 채 집계만 재실행했다.

연구 회귀는 **19 PASS**(새 6 + 기존 관련 13)다. 첫 통합 pytest 수집은 동일 파일명 충돌로 중단됐고 `--import-mode=importlib`로 두 도구를 구분하여 통과했다. 구체적 검증은 미확정 분모, 출처가 다른 목표 시각 분리, unknown 축, DD 경계, OR 중복 제거, outcome에 독립적인 특징/가설 및 기존 확인 경로 계약이다. source hash/cutoff·Python compile·문서 parser 결과는 [검증 영수증](../../tmp/main-enter-pass-opportunity-research-20261007/validation.json)에 기록한다.

원천 재확인에서 완성 분봉 의존 파일 149개 bytes는 일치하여 별도 압축 보존했다. 오늘 AFTER 분봉 8개 경로의 11개 과거 hash 영수증은 장중 갱신되어 현재 bytes로 대체하지 않았다. 대신 현재 분봉 bytes를 새로 고정하고 **원 연구 cutoff 그대로 오늘 첫 반전 125,509개와 삼성 확인점 4개**의 라벨/목표 시각을 전부 재대조하여 차이 0건을 확인했다. 원 hash 불일치와 재대조 결과를 함께 [별도 영수증](../../tmp/main-enter-pass-opportunity-research-20261007/bar-drift-recheck.json)에 보존한다. 과거 원 파일 bytes 자체를 복원한 것으로 표현하지 않는다.

실시간 코드·정책·다른 세션 변경을 수정하지 않았으므로 trading 전체 회귀·배포·PID 소비·provider 재호출은 이번 gate에 포함하지 않는다. 미래 성과와 후단 제출/실현 손익은 미검증이다.
