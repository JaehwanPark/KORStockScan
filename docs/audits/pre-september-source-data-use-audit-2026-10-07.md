**삭제 대상은 9월 이전 파일형 원본 raw와 그 사본·백업이다. ### 날짜 문자열의 오판 방지

타이밍의 삼성 native actual 보완은 [machine_entry_confirmation_study.py](../../src/engine/monitoring/machine_entry_confirmation_study.py)의 `refresh_completed_operating_actuals()`가 원 소유자의 runtime checkpoint를 읽고 `read_native_actual_history()`가 기존 결과 보고서 한 세대를 읽는다. 조사한 경로에서는 8월 원본 raw 재계산을 요구하지 않는다. 보고서/설정 안의 과거 날짜와 실제 원본 open을 구별한다. 초기 매수수량 보고서는 과거 행을 포함해 명시 보존 대상이다.

## 6. 검토와 남은 실행 단계

검토에서 파일 날짜만 사용한 삭제, 7/23 provenance의 오삭제, 혼합 cache/복구 사본 누락, current parent 보고서 오삭제, 과거 폐기일을 현재 source gap으로 해석하는 결함을 반영했다. **DB 전환과 초기 수량 보고서 삭제/행 제거는 이번 계획에서 제거**했다. source inventory의 generic/literal 결과 전체를 현재 실행으로 확장하지 않았다.
