# 삼성전자·삼성전자 제외 종목 분리 심화 연구 결과

## 1. 결정

사용자가 요청한 두 집단의 후속 연구를 기존 원천으로 수행했다. 삼성전자 전체 관측과 fixed-watch를 구분하고, 그 외 종목에서는 삼성전자를 **조건 생성 전에 제외**했다. 시간순 선택, 보유시간별 선택, 원래 후보 유지, 유형별 조건 조합, 실제 관측 간격 재확인까지 검증했다.

**이번 후보군에서는 학습의 양의 성과가 후단 날짜에도 이어지는 새 운영 정책을 확인하지 못했다.** 일부 조건은 상승 경로를 골라냈고 일부 유형 조합은 전체 관측보다 덜 손실이었다. 그러나 반복성·실행 가능한 분모·기존 성공 보존을 함께 충족하지 못했다. 이 결론은 모든 패턴이 없다는 뜻이 아니다.

- 신규 변경: 독립 offline 연구 코드·표적 테스트·계획/리뷰 기록.
- 매매 판정 코드·운영 정책·기존 source producer/consumer 작업본 변경 없음. **541개 운영 정책 hash 동일**, 새 수집/API/provider·정책 발행·커밋·배포·재기동 없음.
- 현재 기본 정책 유지. 이전 연구의 기계 확인 후보2회 회수 결과는 그 범위의 역사적 증거로 보존한다. 이번 연구로 새 live 후보를 등록하지 않았다.
- 실행 소유자: 오늘 checklist `PartitionedContinuousPatternResearch1003`. 기존10/6 자연 수용/PREOPEN owner는 미완료 그대로다.

계획: [집단 분리 상세계획](../proposals/partitioned-continuous-pattern-research-plan-2026-10-03.md). 기존 설계와 연결: [범위 정리](../proposals/main-machine-auxiliary-samsung-scope-reorganization-plan-2026-10-03.md).

## 3. 새로 시험한 방법

1. 완료봉의3/5/10/20분 과거 경로에서 눌림 후 전환, 평균선 재돌파, 고점 돌파, 저점 상승, 방향 효율, 범위 하단 반등, 압축 후 상승 등을 계산했다. 결정 시점보다 최소60초 전의 완료봉만 사용하고 route/날짜/중복/간격/OHLC를 검사했다.
2. 현재 매수 흐름, 가격 반응, 호가 깊이, 직전 관측 대비 흐름 개선을 결합했다. 삼성전자에는 **삼성전자 학습분포에서만** 구한 spread/VWAP 거리/호가/고점 거리 분위수를 추가했다.
3. 그 외 종목은 family·phase·volatility 및 phase×volatility를 학습 관측에서 생성했다. 삼성전자 가격·분포·라벨은 들어가지 않는다.
4. 한 종목에서 신호가 겹치면 해당 horizon의 첫 신호를 선택했다. 첫 신호의 결과가 결손이어도 뒤의 좋은 신호로 교체하지 않았다. native ID가 달라도 같은 종목의 중복 노출을 늘리지 않는다.
5. 9/29→9/30,9/29~30→10/2, fixed-watch9/30→10/2를 각각 동결했다. 모든 날짜는 이전 연구에서 사용했으므로 **탐색 검증**이다.
6. short(3/5/10분),medium(10/20/30분),long(20/30/60분)의 최소 성과와 개별6개 horizon을 모두 검사했다. 보유시간 묶음은 이번 연구의 강건성 비교이며 정식 Main 승격 계약을 대체하지 않는다.
7. 학습 상위종목 제외 재선정, lookback 인접값, 후단 종목 제외, 날짜/원점별 분해, 시간순 신호 구간,99회 symbol-day 순서 회전 최대 탐색 비교를 수행했다. 후자의 수치는 독립 검정 p-value가 아니며, 단일 horizon에는6개 목적의 추가 보정 상한도 기록했다.

| 학습→후단 | 삼성전자 조건 / 학습 행동 vector | 삼성전자 제외 조건 / vector |
|---|---:|---:|
| 9/29→9/30 | 4,200 / 1,044 | 3,240 / 1,256 |
| 9/29~30→10/2 | 4,200 / 1,201 | 3,360 / 1,371 |
| fixed-watch9/30→10/2 | 3,840 / 130 | 해당 없음 |

각 행의 조건은 날짜 사이에 중복될 수 있다. 이를 서로 독립적인 가설 수로 합산하지 않는다. 학습상 동작이 같은 조건은 단순한 조건을 먼저 남겼고, 후단 결과로 동률을 해소하지 않았다.

## 5. 삼성전자 제외 결과

유형을 나누면 양의 학습 조건은 발견된다. 예를 들어10/2 검증용 학습에서 보유시간별 양의 조건은3/5/10/20/30/60분 각각18/6/8/19/19/22개였다. 그러나 학습 1등을 그대로 적용한 후단 결과는 다음과 같다.

| 시간 | 선택된 유형·가격 구조 | 학습 순 CF | 후단 비교 신호 | 후단 순 CF |
|---|---|---:|---:|---:|
| 3분 | recovery_continuation·중간 변동성·5분 방향 효율·양의 흐름 | +0.9634% | 0 | null |
| 5분 | 위 조건 | +0.5633% | 0 | null |
| 10분 | rebound_attempt·낮은 변동성·10분 압축 후 상승 | +0.1483% | 7 | −0.4927% |
| 20분 | distribution·중간 변동성·10분 압축 후 상승 | +0.6550% | 2 | −0.3782% |
| 30분 | 높은 변동성·5분 저점 상승 | +0.6746% | 1 | −1.3972% |
| 60분 | continuation·낮은 변동성·20분 방향 효율·양의 흐름 | +0.7443% | 8 | −0.7890% |

여기서 순 CF는 종목·날짜를 동일 가중한 가격 비교다. 거래 수익률이나 실제 체결 성과가 아니다. 후단 신호 자체가0인 경우는 손실0이나 성공으로 계산하지 않았다.

### 5.1 같은 후보를 계속 유지해도 달랐는가

9/29에서 선택한 `낮은 변동성 + 20분 방향 효율 + 양의 흐름`의60분 조건은9/30 **4신호 +1.4721%**를 보였다. 재학습 없이 같은 후보로10/2를 평가하면8신호 **−0.7890%**다. 하루 양수만 보고 정책을 바꿀 근거는 되지 않았다.

### 5.2 유형마다 다른 조건을 쓰는 조합

동일한 고정 후보군에서 family/phase별로 양의 학습 조건을 선택한48개 fold·유형·horizon 조합도 재생했다. 양의 학습 leaf라도 같은 종목의 중복 노출을 제거해 합치면 전체 성과가 낮아질 수 있음을 확인했다. leaf별 수익을 단순 합산하지 않았다.

그중 **국면별30분 조합은 후단 두 날짜 모두 전체 관측 대비 덜 손실**이었다.

| 날짜 | 전체 관측30분 순 CF | 국면별 조합 순 CF | 비교 신호 |
|---|---:|---:|---:|
| 9/30 | −0.5312% | −0.2863% | 20 |
| 10/2 | −0.3564% | −0.1264% | 12 |

이는 분류력의 단서이지만 실제 정책 개선이 아니다. 기록된 parent `ENTER_NOW`에 그대로 필터를 걸면9/30의 비교 가능38신호 중0개,10/2의39신호 중4개만 남는다. 해당 horizon의 양의 기존 신호는 각각 **0/7, 2/19**만 보존한다. 대부분의 기존 수익 신호를 지우므로 공통 기계 allowlist로 구현할 근거가 없다. 전체 관측 대비 개선을 parent 정책 대비 개선으로 바꿔 표현하지 않는다.

## 6. 실제 기계·보조판정 연결

## 7. 이번 연구의 의미와 다음 계산 경계

1. **삼성전자 분석 대상을31행에 가두지 않아도 된다.** 원본에서206개 fixed-watch 이력을 연결했고,160개 미도달도 비용 차감 가격 비교에 사용했다. 이 손실 없는 분모·원인 분리가 이번에 남기는 재사용 가능한 개선이다.
2. **그 외 종목의 유형 분리가 불필요했던 것은 아니다.** 일부 국면 조합에서 상대적인 손실 구별 단서를 얻었다. 하지만 전체 BLOCK/RECHECK 관측에 잘 맞는 필터가 기존 ENTER의 수익 신호를 지우는 문제를 확인했다.
3. 후속 정책 연구를 한다면 더 넓은 임계값 탐색보다 **이미 실행 가능한 parent ENTER 또는 정확한 soft-confirmation 대기군 안에서의 조건 비교**가 먼저다. 전체 관측 상대 성과와 해당 실행 분모의 승률·성공 보존을 동시에 검증해야 한다. 새 원천 수집을 전제하지 않는다.
4. 고정 종가 CF와 목표-first 회수의 차이를 유지한다. 양자를 연결하는 별도 연구 없이 진입 신호의 양의 CF를 현행 trailing/holding exit 수익으로 바꿀 수 없다. exit 변경은 이번 연구에 포함하지 않았다.

이번 단계는 위 결과로 종료한다. 새 코드에 운영 정책 변경 근거가 생겼다고 주장하지 않는다. 더 좋은 패턴이 존재하지 않는다고도 단정하지 않는다.
