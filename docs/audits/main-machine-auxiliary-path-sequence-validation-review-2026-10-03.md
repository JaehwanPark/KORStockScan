# 기계·보조 AI 결과 분류·관측 순서·장기 경로 검증 결과

소유 계획: [상세 계획](../proposals/main-machine-auxiliary-path-sequence-validation-plan-2026-10-03.md). 실행 소유자: `PathSequenceValidation1003`.

## 결정

P1~P5의 보유 원천 검증을 완료했다. **늦게 상승하는 관측은 존재한다. 다만 이번에 사전 고정한 가격/flow 순서 조건은 날짜 간 양의 비용 반영 성능을 입증하지 못했다.** 결과 분류, 예측 성능, 실제 체결/청산, 운영 정책 승격을 구분한다. canonical label·정책 생성기·실행 정책은 변경하지 않았고, 연구 조건을 live 정책으로 발행하지 않았다. 신규 코드·문서는 미커밋·미배포다.

이전 연구의 원천·결과와 작업본을 보존했다. 9/29·9/30·10/2는 이미 본 날짜이므로 모든 시간순 검증은 재사용 날짜 진단이다. 미사용 독립 holdout 또는 실현 수익 개선으로 표현하지 않는다.

## P2: 관측 순서와 coverage 보완

첫 단계는 같은 날짜·종목·정책·정확 route의 반복 기계 관측을15~180초 간격으로 연결했다. 이전 값 두 개까지 사용하며 최대 과거360초다. 시간 간격 선택은 사후 결과를 사용하지 않는다.

| 날짜 | 전체 관측 | 반복 관측 연결 가능 | 10분 간격 anchor |
|---|---:|---:|---:|
| 9/29 | 3717 | 1498 | 397 |
| 9/30 | 1603 | 54 | 31 |
| 10/2 | 1749 | 132 | 47 |

연결 가능1684행의 날짜 편중이 컸다. 고정한8개 순서 가설·3개 static 대조, 학습에 존재하는 phase 분기로40개 순서 조건·15개 static 조건을 비교했다. 양의 학습 후보는 없었고 후단 선택 수도 희소했다. 이는 반복 관측 원천의 coverage 제약을 포함한 결과다.

이 coverage 차이를 확인한 뒤, 성능에 따라 snapshot 경계를 바꾸지 않고 **기존 저장 완료 분봉**을 이용하는 별도 계획을 고정했다. 마지막6봉을 사용하며 각 봉 timestamp에60초를 보수적으로 더해도 판정 시각을 넘지 않도록 했다. 마지막 완료 시각 지연90초, 인접 봉 간격90초, OHLC·route·source quality·중복을 검사한다. 미래 봉은 feature로 들어오지 않는다. 사후 저장 봉이 당시 live 프로세스에 도착했는지는 별도이며 이번에 입증하지 않았다.

| 날짜 | 과거 분봉 사용 가능 | 10분 간격 anchor | 제외 |
|---|---:|---:|---|
| 9/29 | 3609 | 1258 | 과거6봉 미충족50, 간격/중복49, 지연9 |
| 9/30 | 1521 | 1078 | 과거6봉 미충족28, 간격/중복51, 지연3 |
| 10/2 | 1680 | 1118 | 과거6봉 미충족15, 간격/중복43, 지연11 |

**6810/7069행**에서 기존 가격으로 순서를 구성했다. 8개 분봉 가설은 반전·두 봉 회복·저점 상승·5봉 고점 돌파·5봉 평균 재돌파와 현재 flow/가격 확인 조합이다. phase를 포함해 각 fold에56개 순서 조건과21개 static 조건을 비교했다. 단기/중기/장기와 개별 horizon으로 같은 조건을 재평가했으므로 이를 새로운 고유 조건 수로 중복 합산하지 않는다.

## P3: 미도달 이후에도 상승 경로가 존재하는가?

전체 관측에서 먼저10분 간격 anchor를 선택한 뒤 사후 상태를 분류했다. 결과가 좋은 관측을 먼저 고르는 방식은 사용하지 않았다. 다음 표의 분모는 horizon별 가격·비용이 있는 관측이며 겹치는 시계열을 독립 거래로 간주하지 않는다.

**10분 내 목표·손절 모두 미도달이었던 관측**:

| 이후 평가 시간 | 비교 가능 | 고점이 비용+0.1%를 넘음 | 종료 시점 순 CF 양수 | 평균 종료 순 CF |
|---|---:|---:|---:|---:|
| 10분 | 1563 | 0 | 37 | −0.408568% |
| 20분 | 1479 | 278 | 200 | −0.417175% |
| 30분 | 1410 | 407 | 248 | −0.420081% |
| 60분 | 1259 | **528** | **287** | −0.448829% |

따라서 ‘10분 미도달’로 상승 가능성 부재를 주장할 수 없다. 동시에 이후 상승 사례를 사후 선택한 분류이므로, 이 표 자체는 진입 시점의 예측 규칙이 아니다. 고점 touch는 기존 손절보다 먼저 도달했는지, 호가에서 체결 가능했는지, 실제 청산했는지를 증명하지 않는다.

전체10분 anchor 비교 가능3467건의 endpoint는 gross 평균−0.098388%, 기록 비용 평균0.312766%, 순 CF 평균−0.411154%였다. 실제 비용이 없는데0을 넣은 계산은 없다. 1232건은 관찰 고점이 비용+0.1%를 넘었지만, 그 중565건은10분 종료 순 CF가 비양수였다. 전체60분에서는 같은 고점 조건1855건 중930건이 종료 순 CF 비양수였다. **고점 도달과 고정 시점의 수익 유지가 서로 다른 연구 문제**임을 확인했다.

늦은 목표 도달군도10분 순 CF 평균+0.078771%에서60분−0.019270%로 바뀌었다. 두 horizon의 비교 가능 표본은443/366으로 다르므로 동일 거래의 수익 감소량으로 빼거나 실제 exit 개선값으로 표현하지 않는다. 개별 선정 조건의 여러 horizon 공통 표본 비교는 별도 `common_population`에 보존했다.

## P4: 날짜 간 예측 검증

분봉 단계에서 9/29→9/30,9/29+30→10/2 순서로 조건을 선택했다. 학습 비교 가능10행·5종목·선택 집합 경제성 coverage80%를 요구했다. phase 조건은 학습30관측·5종목부터 정의했다. 이들은 연구의 비교 범위이며 운영 승격 기준을 대체하지 않는다.

여러 horizon의 종목·날짜 동일 가중 평균 중 최솟값으로 고른 후보는 raw 평균과 가중 평균을 함께 양수로 유지하지 못했다. 따라서 **개별3/5/10/20/30/60분 선택**을 별도로 검증했다. 이 비교는 분봉 성능 열람 전에 계획에 추가했고, 후단에서 가장 좋은 horizon을 골라 성공으로 요약하지 않았다.

양의 학습 결과가 있었던 대표 순서 가설:

| 학습→후단 | 학습에서 고른 조건·시간 | 학습 비교 수 / 평균 순 CF | 후단 비교 수 / 평균 순 CF |
|---|---|---:|---:|
| 9/29→9/30 | distribution·5봉 평균 재돌파·10분 | 29 / **+0.158562%** | 27 / −0.283070% |
| 9/29→9/30 | recovery_continuation·5봉 평균 재돌파·60분 | 20 / **+0.401819%** | 18 / −1.319913% |
| 9/29+30→10/2 | range_or_no_setup·가격 반전·30분 | 14 / **+0.115369%** | 4 / −0.208285% |

첫 후보의 후단은27선택 모두 비교 가능했다. 60분 후보는36선택 중18비교 가능,16세션 종료 censor·2가격 gap으로 coverage50%였다. 마지막 후보는5선택 중4비교 가능·1세션 censor로80%였다. 후단4행을 충분한 일반화 증거로 확대하지 않는다.

세 후보는 학습 선택 종목 하나씩 제외하고 재선정해도 각각24/24,20/20,12/12회 같은 조건을 선택했다. 그 안정성만으로 날짜 간 성능 실패를 해결하지 못했다.60분 간격 및 하루 첫 관측의 고정 조건 민감도는 `anchor_sensitivity`에 보존했다.

static 대조 중10/2의 rebound_attempt·현재 flow/가격 양수·5분은 후단2행 평균+0.923741%였다. 그러나 해당 후보의 학습10행 평균은−0.183599%여서 양의 학습 후보가 아니다. 좋은 후단 두 행만으로 정책 후보를 만들지 않았다. 모든 후보·조건별 분모·성공 제외·종목 비중·추가 비용0.05/0.10%p 결과를 JSON에 남겼다.

## P5: 보조 AI 오류 가설

유효 KRX 응답43개, 기존 exact pre-AI 연결14개를 사용했다. 학습34·10/2 9의 원래 PASS를 유지한 상태에서 다음4개 중요도 가설을 비교했다. 새로운 prompt 응답은0이며 prompt 변경의 성능은 계속 unsupported다.

| 가설 | 학습에서 CAUTION 가정 | 관측된 부작용 |
|---|---:|---|
| flow 양수·micro 가격 비양수 | 11 | 학습 성공 제외1/3/5/10분 각각2/1/1/1 |
| 매수 비중50% 초과·micro 가격 비양수 | 11 | 같은 학습 행동과 부작용 |
| spread가 tick보다 큼·micro 가격 비양수 | 7 | 학습 성공 제외1/3/5분 각각1/1/1,10분0 |
| 과거 flow 악화·spread 확대 | 0 | 변경 없이 기존 PASS 유지 |

앞의 세 조건은10/2에서 변경0이었다. 변경이 발생한 조건은 여러 horizon의 학습 성공 보존을 통과하지 못했다. 마지막 조건은 원래 계산에서 비교 가능하지만 행동 변화0이었다. 리뷰에서 이를 개선 후보와 구분하도록 보완했고 최종 선정은0이다. 유효 응답의 전체 분모와 가격/비용이 있는 horizon별 분모를 섞지 않았다.

따라서 flow 양수·가격 정체라는 사실만으로 일괄 CAUTION 처리하는 연구 가설은 현재 결과에서 지지되지 않는다. 기존 응답으로 위험 사실의 오류 유형은 비교할 수 있지만 새 프롬프트가 더 나은 답변을 한다고 주장할 수 없다.

- 새 출력 디렉터리에서 현재 CLI의 `--phase snapshots`를 실행한 뒤 그 실행 소스를 `reviewed-snapshot-phase-source.py`, protocol/receipt를 `snapshot-phase-*`로 보존한다. 하위 `completed-bars` 출력에 `--phase completed-bars`를 실행하고 그 실행 소스를 `reviewed-completed-phase-source.py`로 보존한 다음 같은 출력에 `--phase horizons`를 실행한다. archived 코드와 현재 코드가 다를 수 있으므로 이전 결과와 비교할 때 각 phase SHA를 함께 확인한다.

## 다음 판단

이번 고정 가설의 양의 날짜 재현성 및 실제 실행 가능성은 미입증이다. 운영 정책 승격0을 유지한다. 보유 원천에서 확인된 다음 연구 질문은 **상승 고점 도달 이후 이익이 사라지는 경로를 사전에 구분할 수 있는가, 그리고 기존 entry/holding/exit 규칙을 함께 재생할 때도 이 차이가 남는가**다. MFE를 자동 체결로 가정하거나 기존 손절/청산을 지운 가상 수익으로 답하지 않는다. 새 수집을 이번 완료 조건으로 요구하지 않는다.
