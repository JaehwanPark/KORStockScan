# 삼성·비삼성 연속 가격 반전 전수 재분석 — 2026-10-06

## 1. 결론

**이번에는 기존 기계판정 시점을 사용하지 않고, 보존된 연속 체결 가격 자체에서 하락→상승 반전을 전수 추출했다.** 삼성뿐 아니라 비삼성도 같은 방식으로 탐색했다. 이전 보고서의 30분 묶음·매수압력 전환을 출발점으로 쓰지 않았다. 기존 기계판정은 모든 가격 라벨과 패턴 집계가 끝난 뒤 사례 대조에만 사용했다.

**핵심 패턴은 하락폭이 충분한 상태에서의 초기 가격 반전이다.** 삼성 정규장에서 직전 최대 5분 관측 고점 대비 저점 낙폭 ≥0.8%인 첫 상승은 **2,017/2,683승(75.2%)**, 오늘만 보면 **1,096/1,370승(80.0%)**이었다. 비삼성 정규장은 같은 낙폭 조건에 확인 반등폭 ≤0.3%를 더한 유형이 **102,559/125,956승(81.4%)**이었다. 매수압력·VWAP를 선행 필수 조건으로 두지 않았다.

**이 수치는 반전 시점별 가격선 도달 승률이며 독립된 거래 횟수나 실현 승률이 아니다.** 작은 반전까지 모두 남겼으므로 한 상승에서 여러 후보가 성공할 수 있다. 삼성 정규장의 낙폭 ≥0.8% 성공 2,017개는 최초 목표 도달 시각으로 묶으면 16개다. 그 16개도 독립된 가격 파동이라고 단정하지 않는다. 현재 연구는 후보를 찾는 단계이며 운영 정책은 발행하지 않았다.

## 2. 무엇을 반전 지점으로 분석했는가

예를 들어 `278,000 → 277,500 → 277,500 → 278,000`이면 저점 277,500과 처음 다시 오른 278,000의 관측 시각을 각각 남긴다. 같은 가격의 반복은 방향 변화로 세지 않는다. 반전 추출 단계에는 최소 하락폭·거래량·매수압력·기존 ENTER/BLOCK/RECHECK 조건이 전혀 없다. 하락폭 등의 조건은 **모든 성공·실패 반전을 만든 다음** 비교한다.

각 후보는 자기 반전 확인 시각부터 온전한 30분을 갖는다. 09:05 후보는 09:35까지, 09:06 후보는 09:36까지 평가한다. 30분은 평가기간이다. 이를 탐색 간격·대기시간·임의 중복 제거 창으로 사용하지 않았다.

| 결과 | 기준 |
| --- | --- |
| 저점 반등 여지 | 사후 확인한 저점 체결가격부터 30분, 비용 후 +0.4% 선도달. 저점 매수를 실현 가능하다고 주장하지 않음 |
| 주 집계 | 첫 상승을 확인한 관측의 매도호가로 가상 진입한 뒤, 이후 체결가격이 비용 후 +0.4%에 먼저 도달 |
| 실패 | 비용 후 −3.0% 선도달, 또는 30분 완료까지 목표 미도달 |
| 미확정 | 진입 호가 결손, 관측 순서/연속성 결손, 분봉 내 양 선의 순서 불명 등. 보완 후에도 해결되지 않으면 제외 |
| 후행 | 30분 실패 중 60분 안에 뒤늦게 목표에 닿은 결과. 30분 승리로 바꾸지 않음 |

비용은 기존 계산기의 0.23%를 한 번 적용했다. 목표 체결가격은 `진입 매도호가 × 1.004 / 0.9977`, 소프트손절 가격은 `진입 매도호가 × 0.97 / 0.9977`이다. 평균 손익·EV·손익비·최소 표본 수·강제 관찰 일수로 후보를 걸러내지 않았다. 원천의 매수호가를 출구로 사용한 더 보수적인 관측도 JSON에 별도로 남겼다. 목표 체결가격 도달은 실제 매도 체결을 보장하는 영수증이 아니다.

## 3. 원천 범위·보완·제외

동결 시각은 **2026-10-06T21:14:42.657250+09:00**다. 날짜는 9/21·9/22·9/23·9/28·9/29·9/30·10/2·10/6의 8거래일이며, KRX/NXT/SOR 55개 파티션에서 **8,706,868개 연속 기록**을 추출했다. 삼성 기록은 2,574,304개다. 보존 구간 밖의 거래소 전체 체결까지 갖고 있다는 뜻은 아니다.

같은 일자·종목·시장에 시세 경로가 겹치면 유효 가격 관측수가 가장 많은 한 경로를 주 집계에 사용했다. 동률만 SOR→NXT→KRX 순이다. 이 선택에는 가격 수익률·승패·기계판정을 사용하지 않았다. 모든 경로의 반전 목록도 따로 보존했다. 10/6 삼성 프리는 SOR 70개보다 NXT 22,455개 기록이 촘촘해 NXT 경로가 선택됐다. 서로 다른 경로의 가격을 한 후보 안에서 이어 붙이지 않았다.

순서가 뒤집혀 도착한 격리 체결 등을 정상 가격으로 덮어쓰지 않았다. 대신 같은 날짜·종목·요청 코드의 보존된 증권사 완성 분봉과 공유 WS 완성 분봉으로 미확정 결과를 보완했다. 새 반전이나 승리를 임의 생성하지 않았고, 이미 확정된 라벨은 바꾸지 않았다. 분봉 경계·같은 봉 양 선 접촉은 순서를 모르면 제외했다. 시장 경계에서 실제 경로가 끊긴 후보도 실패로 채우지 않았다.

주 집계에서 보완 전 판정 가능 595,752개가 **763,496개**로 늘었다. 총 1,495,955개 반전 중 732,459개는 여전히 미확정으로 제외했다. 반전 후보가 나온 종목은 1,096개다. 원천 보완 전후 결과를 분리해 저장했다.

확정된 조기 승리는 남고 긴 관측이 필요한 실패는 결손으로 빠질 수 있으므로, 제외율이 다른 패턴의 승률 차이를 무조건 실제 정책 개선으로 단정하지 않는다. 이 점을 새 채택 문턱으로 만들지는 않는다. 후보별 제외 수를 그대로 공개한다. 외부 차트의 거래 경로·가격 의미가 불명확한 값을 실제 체결가격 대신 채우지 않았다.

라벨을 완성한 뒤 옛 기계 기록을 대조했다. 09:05:01 반전 직전 **09:04:47은 source_invalid**, 이후 **09:06:22는 BLOCK**이었다. 09:10:08 반전 직전 **09:10:00은 source_invalid**, 이후 **09:11:54는 RECHECK**였다. 따라서 기존 판정 행만 모집단으로 삼으면 반전의 시작을 놓칠 수 있다는 지적이 맞다. 인접 시각 대조이며, 이 표만으로 주문 부재의 단독 원인이나 해당 틱에서의 실제 주문 가능성을 증명하지는 않는다.

## 8. 판정 정책으로 옮길 때의 단순 구조

1. **상시 관측:** 기계의 직전 BLOCK/RECHECK 결과와 관계없이 새 가격의 하락 구간·저점·첫 상승을 계속 갱신한다. BLOCK이 다음 반전 탐색을 중단시키지 않는다.
2. **RECHECK:** 시장·종목 유형에서 선택한 낙폭 상태에 들어왔지만 첫 상승이 아직 나오지 않았다면 반전을 기다린다. 임의의 30분 평가 묶음이나 5분 준비시간을 두지 않는다.
3. **ENTER 후보:** 첫 상승이 관측되고 해당 유형의 가격 패턴을 충족하면 후보 시각·진입 기준 호가를 고정한다. 뒤의 조건 확인으로 놓친 상승폭을 별도로 측정한다.
4. **BLOCK 방향:** 해당 유형의 높은 승률 조건을 벗어난 진입은 제외하되 연속 관측은 유지한다. 실제로 30분 뒤 실패했는지를 현재 입력으로 쓰지 않는다.
5. **평가:** 후보마다 비용 후 +0.4%·소프트손절 −3.0%·30분 선도달 승률을 누적한다. 60분 뒤 회복은 후순위로 별도 기록한다.

위는 연구 결과를 옮길 구조다. 완성된 실시간 3분류기나 실주문 정책으로 검증·배포했다는 뜻은 아니다. 반전 탐지와 고점·낙폭 상태는 기존 기계판정 이전의 연속 시세 소비자가 소유해야 한다. 장후에는 반전 전체 목록과 성공·실패·미확정 라벨을 누적하고, 기계판정은 사후 누락 대조에만 조인하는 방향이 맞다.

## 9. 검증과 산출물

기존 장후 실행 코드·정책·프로세스는 변경하지 않았다. 독립 연구 디렉터리에서 단일 프로세스·낮은 CPU 우선순위로 실행했다. 전체 기록을 동시에 보관하지 않도록 종목/파티션별 집계를 사용했다.

리뷰에서 반전 확인 틱을 “직전 고점”에 섞는 문제와 불필요한 5분 연속 관측 대기조건을 수정했다. 반전 모집단과 결과 라벨은 바꾸지 않고 과거 특징만 재계산했다. 보완 시 분봉의 사전/사후 경계 혼입, 양 선 선후 불명, 미확정 행을 실패로 만드는 오류를 검사했다. 그림의 종목과 사례 마커 연결도 수정·재확인했다.

21개 테스트가 통과했다. 전수 반전·접두 구간 불변성·각 후보의 개별 30분·정확한 시간/비용 경계·손절 선도달·결손·원천 선택의 승패 독립성·완성 분봉 보완·미래 확인 틱의 과거 고점 혼입 방지를 포함한다. 파일 링크·Python compile·문서 parser와 증거 해시는 최종 검증 파일에 기록한다. 거래 테스트·배포·장후 전체 재생성·외부 동기화는 실행하지 않았다.
