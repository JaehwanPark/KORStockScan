# 전 종목 상승지속·반등 경로 연구와 추가 후보 소비 계획

## 1. 소유와 적용 순서

10/7 사용자 요청에 따라 진행 중인 복수정책 구현을 수정하지 않고 추가 패턴의 등록 인계 자료를 준비하며 전 종목 경로 연구를 실행한다. 최초 삼성 대상 요청을 후속 전 종목 요청으로 확대한다. 실행 owner는 [오늘 체크리스트](../checklists/2026-10-07-stage2-todo-checklist.md)의 `DirectFamilySourceRepairMainMechanisticEntry`다. [현재 복수정책 계획](main-all-scope-registered-multi-policy-implementation-plan-2026-10-07.md)의 수동 가설→고정 등록→장후 비교→선택된 정책 실시간 평가 순서를 따른다.

현재 개발 catalog의 수동 후보는 S1/S2/D1/H1/A1/J1/G1~4다. [추가 유형 연구](../audits/main-enter-pass-scarcity-and-opportunity-union-research-review-2026-10-07.md)의 유형들은 그 10개와 별도의 후속 등록 배치이며 현재 등록·선택·적용됐다고 표시하지 않는다.

## 2. 추가 유형의 소비 계약

1. 각 유형을 English ASCII의 고정 branch ID, symbol group, market/route/item, 가격대, 정확한 포함/제외 경계와 필요한 특징으로 변환하고 definition/result/source/code hash를 결속한다.
2. 첫 반전 유형은 현재 `registered_pattern` 평가기의 비교 연산으로 표현한다. `confirmation_pct`를 사용하는 rebound 필터는 현재 catalog feature alias가 없는지 검토하고 지원 보완 항목으로 명시한다. 알 수 없는 필드를 무시하지 않는다.
3. 등록 시 기존 10개·당일 실제 적용 버전·현 정책과 신규 단독·연구된 합집합만 명시적으로 비교 목록에 추가한다. 43개 일반 후보의 powerset을 만들거나 장후에 새 threshold grid를 만들지 않는다. 다른 가격대/scope에 그룹 합산 승률을 복사하지 않고 native scope에서 재생한다.
4. 누적 raw 도달률 우선 조합과 기존보다 낮지 않은 도달률에서 기회 수를 늘린 조합을 별도 비교 대상으로 보존한다. 기존 성공 100%/80% 보존·최소 표본/일수·holdout·EV 문턱을 추가하지 않는다.
5. 기계 평가의 확인 시점에 실제 보조 input/prompt/schema를 구성하여 원 응답 공통 점에서 PASS 성과를 비교한다. 연구 WIN/FAIL·승률·성공을 암시하는 유형명은 입력에 넣지 않는다. provider 요청 bytes가 같을 때만 재사용한다.
6. 선택된 portfolio만 실시간에 소비하고 동일 확인 틱의 여러 branch는 하나의 intent/보조 호출로 묶는다. 평가 신호 수를 주문·수량으로 더하지 않는다.

인계 배치의 기본 scope는 **SOR REGULAR**이다. PRE/AFTER/NXT/KRX 적용은 별도 동일 정의 재생/지원 검증을 거쳐 scope를 명시한다. 이후 장후작업은 등록 후보와 적용 버전만 비교하며 새로운 패턴 생성은 수동 연구가 소유한다.

## 3. 전 종목 경로 가설

보유 9일 SOR REGULAR/PRE의 기존 normalized 원천과 직전 연구의 오늘 접두(REGULAR 15:20, PRE 08:50 이전)를 사용한다. 원천과 완성 분봉을 bytes/hash로 고정한다. 기존 ENTER/AI 응답 여부로 모집단을 제한하지 않는다.

삼성·두산·HPSP·알테오젠·주성전자·그 외 전 종목으로 분리하고 일반 종목은 가격대/당일 종목 흐름/60초 속도/고저 구조로 구분한다. KRX/NXT/AFTER는 이번 SOR 결과를 복사하지 않고 후속 scope 재생 대상으로 명시한다.

상승지속형 모집단은 **첫 하락이나 반전이 필요 없는 전체 유효 틱**이다. 기존 반전 anchor만 소비하면 눌림 없는 상승이 사전에 제외된다.

- 최근 60초 고점 돌파: 현재 틱 이전 연속 경로의 고점을 돌파한 최초 점. 유지 1/3초와 비교한다.
- 고저점 동반 상승: 직전 30초 대비 최근 30초 고저점이 모두 높고 60초 수익률이 0.05/0.1/0.2% 이상으로 전환한 최초 점.
- 상승 모멘텀: 60초 수익률이 0.05/0.1/0.2% 이상으로 전환한 점과 1/3초 가격 유지 확인. 10틱 buy pressure 60% 이상을 추가한 고정 가설도 비교한다.
- 조건 false→true 전환만 새 신호로 계산한다. 결손을 false로 바꾸어 재신호를 만들지 않는다. 같은 실제 확인점은 합집합에서 한 번 계산한다.

- 저점 재시험 후 회복: 원 저점 재접촉을 새 가설의 시작으로 보고 원 FIRST 가격 또는 원 직전 고점을 회복하는 최초 점을 찾는다. 허용 재하락은 원 저점 미만 0/0.2%, 확인 상한은 30/120초다.
- 고점 재돌파: 같은 연속 경로에서 원 직전 고점 이상으로 회복하는 점을 찾고, 저점 재시험을 허용하는 정의와 비교한다.
- 회복 유지: 원 FIRST 가격 또는 재시험 후 회복 가격 위에서 1/3/5초 유지한 최초 관측점으로 평가한다. 경로 단절·확인 이전 가격 이탈은 성공 처리하지 않는다.
- 체결 방향 전환: anchor 10틱 buy pressure≤40%에서 확인점 ≥60/70%로 전환하고 가격 회복도 동시에 충족하는 최초 점을 찾는다. 방향·수량이 없으면 unknown이다.
- 두 번의 상승: 단일 uptick 이후 두 번째 가격 상승까지 관측하고 원 가격/고점을 회복한 점을 비교한다.

최초 반전의 원 저점·고점을 경로 anchor로 보존하고, 실제 확인 시점까지 알려진 낙폭/종목 흐름/60초 속도/고저 구조로 유형을 판정한다. 확인 뒤에 알게 된 미래 최고가나 최종 목표 도달을 특징으로 쓰지 않는다. 각 branch의 실제 확인 ask에서 **새 30분**을 시작하고 비용 0.23% 후 +0.4%/soft -3% 선도달을 계산한다. 10분 이후 기존 가격과 정확 item 완성 분봉을 활용하며 미확정은 실패·0수익으로 바꾸지 않는다.

실행 1차는 고점 돌파·모멘텀·고저 상승의 즉시/체결 방향/1·3초 유지 28개, 재시험·고점 회복 12개, 첫 회복 1·3·5초 유지 3개 총 43개 확인 정의다. 유형 필터는 실제 확인 시점까지 알려진 특징으로 판정하며 최초 anchor 미래 수익을 사용하지 않는다. 기본 단일축/흐름·속도·구조 3축 비교 뒤에는 **가격대(일반 종목) × 종목 흐름 × 60초 속도 × 고저 구조 × 낙폭**의 유한 유형을 전수 비교한다. 추가 조건은 ANY/호가 간격≤0.1%/거래량비≥1/10틱 BUY≥60%/60초 VWAP 이상으로 사전 고정한다. unknown 유형은 적합성 미입증으로 제외하며 현 데이터에서 탐색한 결과라는 표시를 유지한다. 원 저점 재시험을 허용한 SECOND_UP와 체결 방향 전환 경로는 별도 후속 가설로 남겨 43개에 이미 포함됐다고 하지 않는다.

## 4. 검토와 종료

격리 도구 위치는 `tmp/main-continuation-path-research-20261007/`다. 운영 engine root/registry/상태·다른 세션의 작업본을 수정하지 않는다. 자체 리뷰→수정→미래 접두 불변·경로 단절·재시험 경계·새 ask/30분·중복 확인점/목표 시각·source hash 회귀→재리뷰로 닫는다.

결과는 신규 단독 및 기존/S1/S2/고정 후보와의 합집합 성과, 오늘 실제 매칭, 실패/미확정/목표 시각 집중을 함께 공개한다. 현 누적 기준보다 높은 도달률 또는 같은 도달률의 추가 기회가 있으면 고정 후보로 인계한다. 없으면 검증한 가설과 제약을 남기고 연구 성공을 주장하지 않는다. 신규 경로의 FSM은 현재 개발의 NEXT_UP 5초만으로 구현됐다고 간주하지 않고 필요한 공통 경로 지원을 정확히 표시한다.
