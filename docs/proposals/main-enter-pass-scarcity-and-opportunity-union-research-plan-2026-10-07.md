# Main ENTER_NOW·PASS 희소 원인과 누적 병행 패턴 연구

## 1. 요청과 범위

10/7 사용자 지시에 따라 다른 세션의 복수 정책 구현과 별도로 수동 패턴 연구를 진행한다. 오늘 기계판정·보조판정까지의 희소 원인을 정확한 판정 ID로 분해하고, 오늘 놓친 유형을 전체 보유 누적 원천에서 비교한다. 이후 제출·체결 경로는 이미 확인된 기계적 결함과 후속 연구 대상을 구분하는 데 필요한 기존 근거만 읽는다.

실행 owner는 [현재 체크리스트](../checklists/2026-10-07-stage2-todo-checklist.md)의 `DirectFamilySourceRepairMainMechanisticEntry`에 연결한다. 이번 작업은 연구 도구·계획·감사 결과를 소유하며 운영 코드, 정책, 배포/재기동 및 다른 세션의 작업본을 변경하지 않는다.

## 2. 원천과 분모

- 오늘 trace/payload/request/outcome 및 기존 funnel 요약의 종료 byte/시각을 고정한다. Main의 판정 attempt, 보조 실제 응답, 주문 권한 없는 probe, 신호/확인점, 실제 제출을 각각 센다. 오늘이 진행 중이면 종료 시각까지의 결과로 명시한다.
- 시장 원천은 기존 native normalized 누적 manifest와 이미 검증한 연구 cache를 우선 재사용한다. 오늘 raw는 명시적 오프라인 연구 입력으로 고정 크기까지 한 번 정규화하고 연구 디렉터리에만 저장한다. 후속 원천 조회나 API 호출을 추가하지 않는다. 진행 중 raw의 반복 전체 진단 scan은 하지 않는다.
- SOR·NXT·KRX와 PRE/REGULAR/AFTER를 구분한다. 연구 collector와 실제 운영의 sequence namespace가 다르면 가까운 시각으로 exact join하지 않는다. 지원 원천이 없는 시장/유형은 무표본으로 남긴다.
- native 첫 반전 전체에서 ENTER/BLOCK/RECHECK와 무관하게 특징을 계산한다. 10분 이후 기존 가격과 같은 item 완성 분봉을 사용하되 실제 확인 ask부터 30분, 비용 0.23%, 비용 후 +0.4%/soft -3%의 동일 라벨을 적용한다. WIN/FAIL_STOP/FAIL_TIMEOUT/UNRESOLVED를 구분한다.

## 3. 실행 순서와 가설

1. 오늘 Main/PROBE·종목군·시장·정책 버전별 기계 action, no-current-signal, 조건 불충족, 필수 특징 결손, claim 만료/교체를 분해한다. 실제 ENTER의 보조 호출/미호출·PASS/veto/오류를 정확한 ID로 추적한다.
2. 오늘 정상 가격 기회의 특징 분포와 현 정책의 필터 통과 비율을 비교한다. 깊은 DD 요구, volume 요구, 첫 반전 시점 전달, 얕은/느린 상승·상승 중 조정·하락 후 회복 유형을 우선 점검한다.
3. 삼성·두산에너빌리티·HPSP·알테오젠·주성 및 나머지 종목을 분리한다. 시장·가격대·세션 추세·ret60 속도·고저 구조·DD5·spread·volume의 고정 유형을 누적 원천에서 탐색한다. 신규 특징/확인 방식의 추가 단계는 결과를 본 뒤 추가한 가설임을 기록한다.
4. 단독 후보의 높은 승률뿐 아니라 현 정책/이미 연구한 후보와의 합집합에서 **중복을 제거한 추가 기회·추가 WIN·추가 실패·미확정**을 계산한다. 같은 승률에서 기회를 늘리는 후보를 연구 성과로 별도 제시한다. 운영의 동률 incumbent 선택 규칙을 이 연구에서 변경하지 않는다.
5. 오늘에는 매칭되지만 누적 승률이 낮은 후보, 누적 성과가 있지만 오늘 매칭이 없는 후보를 구분한다. 최소 표본/일수/holdout/기존 성공 보존 문턱은 추가하지 않는다. 적은 표본·날짜/종목/목표 접촉 집중은 그대로 공개한다.

## 4. 검증과 결과

도구 위치는 이번 `tmp/main-enter-pass-opportunity-research-20261007/`, 결과는 `docs/audits`로 둔다. 기존 역할 패키지의 읽기·순수 재생 함수를 사용하고 운영 producer/최신 보고서에 쓰지 않는다. 소스 hash, cutoff, 누락/제외 원인과 분모 합계, 후보/합집합 중복 제거, future-prefix 불변·동일 label 계약을 검증한다. 필요한 targeted 회귀와 문서 print-only parser를 실행한다.

완료 결과는 오늘 ENTER/PASS 희소의 증거 있는 원인, 누적 비교한 유형별 추가 정책 후보, 후단으로 넘길 별도 과제와 원천/검증 한계다. 패턴 발견을 실제 제출·체결 또는 실현 수익으로 표현하지 않는다.

## 5. 이번 실행 결과

[실행 감사](../audits/main-enter-pass-scarcity-and-opportunity-union-research-review-2026-10-07.md)에 판정 832건/ENTER 4건/실제 PASS 2건과 누적 원천 9일·6,882개 유형/필터 조합의 결과를 기록했다. 성능 비교는 SOR PRE/REGULAR을 분리했고 주 결과는 정규장이다. 다른 세션의 구현과 운영 변경은 분리했다.

도달률 우선 합집합과 최초 기준 도달률을 유지하는 기회 수 우선 합집합을 모두 계산했다. 후자는 중간에 얻은 최고 도달률까지 매 단계 보존할 것을 요구하지 않는다. 추가 성공·실패·미확정과 오늘/누적을 함께 남겼다. 삼성은 오늘의 추가 확정 성공까지 입증하지 못했다. NXT 전용 PRE에 대한 적용성, 이미 연구된 등록 후보 10개 전체와의 최종 공동 조합, 삼성의 지속 경로 가설, PASS 이후 후단은 감사 §8의 인계 대상으로 구분했다.
