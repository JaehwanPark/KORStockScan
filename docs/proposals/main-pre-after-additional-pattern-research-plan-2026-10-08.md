- 10/8 후속 사용자 정정에 따라 실제 운용 경로를 **PRE=NXT `symbol_NX`, REGULAR=SOR `symbol_AL`, 통합 AFTER=SOR `symbol_AL`**로 고정한다. 이번 신규 연구는 PRE NXT와 AFTER SOR 두 범위다. 128 route 정책 셀의 존재를 전 경로 실운용으로 해석하지 않는다.
- 10/7 장후 기계 보고서가 실제 읽은 누적 normalized 원천 중 위 두 범위만 해시로 고정한다. 정정 전 계산된 다른 19개 파티션은 `out_of_scope_partitions`로 분리하며 후보 선별/합집합/등록 인계에 사용하지 않는다. 추가 가격 조회나 오늘 장중 파일 전수 재수집은 하지 않는다.
- 비교 기준은 10/8 활성 v5 bundle `cdacf6eed9d77e95d0bdf1a417ec2549323ea2491b91e41b8f948b900434895f`의 **해당 종목군·세션·가격대·경로**다. 연구 시작 후 current 변경은 고정 기준을 바꾸지 않는다.
- 삼성, 두산, HPSP, 알테오젠, 주성, 일반 비삼성을 나누고 삼성 이외는 실제 적용 가격대까지 분리한다. 서로 다른 venue/item 자료를 합쳐 한 정책의 성과로 만들지 않는다.

## 3. 유한 수동 가설

기존 전 종목 연구의 causal 특징/확인 함수를 재사용한다. 격리 도구 위치는 `tmp/main-pre-after-pattern-research-20261008/`이며 실시간 engine이나 장후 자동 탐색 기능을 신설하지 않는다.

1. 첫 상승반전 자체와 첫 회복 1/3/5초 유지.
2. 저점 재시험 후 FIRST/원 고점 회복, 원 고점 재돌파: 30/120초, 저점 하회 허용 0/0.2%.
3. 선행 하락을 요구하지 않는 60초 고점 돌파, 60초 수익률 0.05/0.1/0.2% 전환, 고저 동반 상승+속도 전환.
4. 상승지속 확인은 즉시/BUY10 60% 이상/1·3초 유지로 구분한다. 조건의 알려진 false→true 전환만 새 신호다.
5. 확인 시점의 종목 흐름(UP/NEUTRAL/DOWN), 속도, 고저 구조, 5분 낙폭을 단일축 및 관측된 조합으로 비교한다. 추가 조건은 ANY/스프레드≤0.1%/거래량비≥1/BUY10≥60%/60초 VWAP 이상이다. 외부 시장 지수 국면으로 부르지 않는다.

## 4. 평가·선별

- 실제 확인 ask부터 새 1,800초, 비용률 .0023, 순 목표 +.4%, soft stop -3% 선도달. `WIN / FAIL_STOP / FAIL_TIMEOUT / UNRESOLVED`를 별도 집계한다.
- 10분 이후 원천도 소비한다. native 경로가 불완전하면 기존 동일 item 완성 분봉을 사용한다. 신호 특징은 확인 이전 접두만 읽고, 결과 평가는 그 이후 30분의 보유 가격자료를 읽는다. 명시된 source cutoff가 있을 때만 native 소비자와 동일하게 제한한다. 마지막 tick 시각을 임의의 결과 관측 종료로 삼아 이미 있는 이후 분봉을 버리지 않는다. 진입 세션별로 집계하고 결과 보조 자료가 다음 세션에 걸리는 경우 시간 근거를 그대로 보존한다.
- 전체 누적을 탐색하며 10/7 매칭 유무로 과거 후보를 사전에 탈락시키지 않는다. 날짜별 결과·종목 수·목표 도달 시각 집중도를 공개한다. 같은 데이터에서 탐색·평가했다는 한계를 명시하고 독립 검증 성과로 표현하지 않는다.
- 동일 확인점은 정책 간 합집합에서 한 번만 센다. 신규 단독, 기존, 기존+신규, 고정 추가 조합을 비교한다. 누적 raw 승률과 추가 성공 기회를 우선하며 기존 성공 100%/80% 보존·최소 표본·최소 일수·holdout·EV gate는 추가하지 않는다.
- 기존 기준에 확정 결과가 없으면 개선 입증이 아닌 `baseline_unresolved` 후보로 분리한다. 무표본/원천 결손/조건 불일치도 분리한다. 높은 승률만 있고 추가 WIN이 없는 중복 후보를 등록 우선 후보로 제시하지 않는다.
- 연구 확인점은 실제 주문·독립 거래·보조 PASS·실현 수익이 아니다. 독립 탐지와 보조 입력/중복 제거의 실제 지원 여부는 별도 등록 계획에 명시한다.
