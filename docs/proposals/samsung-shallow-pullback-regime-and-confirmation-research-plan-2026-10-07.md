# 삼성 얕은 눌림: 흐름 분리·확인 시점 후속 연구

## 1. 목적과 범위

사용자의 “삼성 추가 연구를 이어가자”에 따라 앞선 [33개 가설 결과](../audits/main-fixed-watch-submit-lineage-and-samsung-shallow-pullback-research-2026-10-07.md)를 확장한다. 삼성 정규장 자체 가격 흐름에서 작은 낙폭 후 상승을 찾아 기계판정 후보를 비교한다. 보조 AI 결과를 특징이나 모집단에 섞지 않는다.

연구의 종료 조건은 아래 고정 가설을 기존 원천으로 실행하고, 흐름별 후보 순위·진입 확인 효과·결손 및 구현에 필요한 상태 계약을 검증하는 것이다. 운영 정책 변경·발행·배포·재기동은 이번 연구의 실행 범위에 포함하지 않는다.

기준은 10/7 체크리스트의 Main 연속 반전 override다. 비용 0.23%, 진입 기준 30분 내 비용 후 +0.4%/soft -3% 선도달, 누적 raw 승률을 사용한다. 최소 표본/일수·holdout·EV·손익비·기존 성공 100%/80% 보존을 탈락 조건으로 추가하지 않는다. 표본·미확정·날짜 집중은 수치로 공개한다.

## 2. 입력 고정

- 005930, SOR 정규장. 기존 검토된 9/21·22·23·28·29·30·10/2·10/6 동결 가격/반전 원천과 10/7 기존 파일의 고정 바이트 접두를 사용한다.
- 앞선 09:39 동결 결과는 보존한다. 이번에는 별도 디렉터리에 새 접두·SHA·종료 시각을 고정한다.
- 과거 source/normalized/event 해시를 확인한다. 존재하는 동일 source item 완성 분봉만 보완 라벨로 사용한다. 분봉 자료도 따로 동결하며 오늘 동결 수신 종료 시각 이후 가격은 제외한다.
- 가격 노후화·native sequence/epoch 단절은 원천 경로에 남겨 연결을 끊는다. 틱이 없는 구간을 현재 가격으로 채우거나 미확정을 실패/0으로 바꾸지 않는다.
- 새 API/provider 호출이나 새 원천 수집은 하지 않는다. 원천 복사 범위는 삼성 행과 필요한 분봉으로 제한한다.

## 3. 당시 관측 정보로 흐름 분리

아래 세 가지를 독립 비교한다. 모두 최초 반전 시각에 고정하고 후행 결과를 보지 않는다. UP/DOWN/FLAT은 삼성 종목 자체의 가격 구간이다. 외부 지수 상승장/하락장으로 해석하지 않는다.

| 구분기 | UP | DOWN | FLAT / UNKNOWN |
| --- | --- | --- | --- |
| 직전 60초 수익률 | ≥+0.2% | ≤−0.2% | 사이값 / 정상 연속 관측 부족 |
| 세션 최초 정상 관측가격 대비 | ≥+0.4% | ≤−0.4% | 사이값 / 기준 원천 없음 |
| 직전 두 30초 구간 고점·저점 | 둘 다 상승 | 둘 다 하락 | 혼합·유지 / 구간 부족 |

세션 기준가격은 공식 시가가 아니라 최초 저장된 정상 관측가격이다. 날짜별 최초 관측 시각·가격을 공개한다. 두 30초 구간은 `[t−60,t−30)`와 `[t−30,t]`를 사용하며, 체결 간격이 길어 빈 구간이 생기면 UNKNOWN으로 둔다.

## 4. 패턴과 확인 시점

모집단은 직전 낙폭 ≤0.4% 후 첫 상승이다. 가격/반전 전체가 모집단이며 기존 ENTER_NOW/BLOCK/RECHECK는 사후 소비 대조에만 사용한다.

확인 방식 7개:

1. 첫 상승 즉시.
2. 첫 상승 가격을 넘는 다음 상승, 최대 5초/15초.
3. 해당 하락 직전 고점 회복, 최대 5초/15초. 이미 회복했으면 즉시.
4. 원 저점보다 높은 재눌림 후 다음 상승, 최대 15초/30초.

첫 반전 이후 원 저점에 다시 닿으면 해당 확인 후보는 종료한다. 원천 단절 전까지 확인되지 않으면 `confirmation_path_censored`, 정상 관측에서 시간만 끝나면 `confirmation_timeout`으로 표시한다. 이 둘은 진입 후 실패 라벨이 아니다.

선행 필터 10개:

- 제한 없음.
- 과거 60초 수익률 ≥0.2%.
- 과거 60초 VWAP 대비 ≥0.1%.
- 최근 30초 저점 상승.
- 최근 30초 고점·저점 동반 상승.
- 최초 세션 관측가격 대비 ≥0.4%.
- 세션 상승 + 60초 수익률 ≥0.2%.
- 세션 상승 + 최근 저점 상승.
- 60초 상승 + 최근 저점 상승.
- 관측 5분 낙폭 0.4~0.8% + 과거 60초 수익률 ≥0%.

총 70개 필터·확인 조합을 세 구분기의 각 흐름 안에서 비교한다. 기존 DD5 ≥1.2%도 같은 흐름 분류로 대조한다.

## 5. 비교와 수용 의미

- 추가 확인 시점의 매도호가로 새 진입 가격을 잡고 그 시점부터 30분 라벨을 다시 계산한다. 원 저점·첫 진입 가격을 늦은 진입에도 그대로 쓰지 않는다.
- 후보별 anchor·확인된 진입·서로 다른 진입 시점·승/손절/시간종료·미확정·필터 결손·미확인 사유·목표 도달 시각 집중·날짜별 결과를 공개한다.
- 같은 원 반전에서 첫 진입과 확인 진입 모두 라벨이 확정된 쌍을 따로 비교한다. 첫 승리→새 실패도 그대로 남기며 후보 탈락 문턱으로 만들지 않는다.
- 같은 흐름의 무필터 첫 반전, 이전 연구 후보, 현재 깊은 낙폭 후보와 비교한다. 현재 규칙이 매칭 0인 구간의 승률을 0%로 만들지 않는다.
- raw 승률 순위에 최소 표본이나 별도 보정값을 넣지 않는다. 예컨대 1/1 후보는 100% 그대로 표시하되 원천·미확정·날짜 집중을 함께 제시한다.

## 6. 구현 가능성 점검

연구 후보가 확인되면 다음 상태가 실시간에도 같은 의미로 생산되는지 점검한다.

- 날짜·item·route·native epoch에 결속된 세션 첫 관측가격과 연속 과거 특징.
- 최초 반전 ID와 동결된 흐름·저점·고점·만료 시각.
- 추가 확인을 실제로 관측한 새 시각·매도호가·source ID.
- 신규 kernel/event/payload hash 및 기존 hard source/order/custody guard 보존.
- Main 평가가 실제 읽은 first-turn freshness 창과 연구 전수 틱 후보의 차이.

조건부 흐름 정책·확인 방식은 현재 단일 rule loader에 자동 적용하지 않는다. 세션 anchor 복원과 pending confirmation 상태, 새 후보 생성기/consumer parity가 구현 과제인지 결과 보고서에 구분한다.

## 7. 검증과 산출물

`korstockscan-review-gate`에 따라 self review→보완→재검토→표적 검증을 수행한다. 새로운 Python runtime module은 만들지 않고 `tmp/samsung-shallow-regime-confirmation-20261007/`에서 오프라인 분석한다.

- 원천/이벤트 SHA와 기존 첫 진입 라벨 재현.
- 과거 특징·구분기의 접두 불변성 및 정확한 시간 구간 경계.
- 원 저점 재접촉·경로 단절·확인 없음과 진입 실패의 분리.
- 확인 진입의 비용 목표·30분 시계 재시작.
- 분모 보존과 같은 반전 paired 비교.
- 문서 link/authority 검토, print-only backlog parser, compile, git diff whitespace.

실행 결과는 별도 [연구 보고서](../audits/samsung-shallow-pullback-regime-and-confirmation-research-2026-10-07.md)에 기록한다.

## 8. 실행 중 추가 분리와 마감

첫 비교에서 확인 대기를 붙인 후보의 raw 승률 상승과 같은 반전의 진입 시점 효과가 달랐다. 따라서 같은 동결 원천·70개 조합을 그대로 두고 상승 흐름 내 관측 5분 낙폭을 `<0.4`, `0.4~0.8`, `>0.8~<1.2`, `≥1.2`, unknown으로 추가 분리했다. 이는 사후 탐색 확대이며 독립 확인 연구로 표기하지 않는다. 별도 최소 표본·holdout 문턱은 만들지 않았다.

같은 확인 틱에 여러 원 반전이 연결되면 원 반전 수와 실제 서로 다른 확인 시점 수를 함께 제시한다. 최종 선호 후보, 더 작은 낙폭의 보조 연구 후보, 두 후보 결합 결과를 각각 남겨 서로 다른 분모를 섞지 않는다. 이 실행은 [검토된 연구 결과](../audits/samsung-shallow-pullback-regime-and-confirmation-research-2026-10-07.md)로 마감한다. 현행 정책·프로세스 소비 완료로 표시하지 않는다.
