표는 표시용 반올림이다. 계산은 이전 학습 결과 `48.21999931335449bp`, `30.869999885559082bp` 및 동일한 float32 비교 의미를 고정한다. C 판정에는 VWAP가 필요하지 않으며, 사용하지 않는 입력 결손으로 분류를 막지 않는다. A 여부는 알지만 A1 입력이 없으면 `A_subtype_unknown`으로 남겨 A의 나머지와 구분한다. 체결 용이성 점수60은 체결 확률60%가 아니다.

활용은 다음 순서로 한다.

1. **장후 분석의 비교 단위:** 유형별 목표/손절/미도달/결손, 비용, 확인 지연, 종료 결과를 보고한다. 원판정과 분류를 따로 저장한다.
2. **가설 검증의 범위:** A1 안에서 진입·청산 효과를 분리하고 A의 나머지와 비교한다. 특정 유형의 평균을 모든 종목 공통 임계값으로 확장하지 않는다.
3. **정책 후보의 scope:** 검증된 경우에만 유형 조건을 기존 Main 판단에 적용한 후보를 실제 parent와 격리 비교한다. `A1 => ENTER_NOW` 직접 변환은 이번 분류의 기능이 아니다.
4. **운영 구현 검토:** 정확한 행동 개선, 기존 guard 유지, source/비용/native 계약이 확인된 후보에 대해 후속 구현안을 작성한다. 감시 슬롯 재배분, 매수 수량 조정, 독립 위젯/에피소드 정책 변경은 별도 설계 범위다.

## 4. 실행 순서와 완료 조건

### P0 원천과 가설 고정

기존 세 날짜의 projection, machine capture, completed-price cache, retained quote/trade, 비용 계약, parent 정책과 연구 kernel의 physical SHA를 실행 manifest에 기록한다. 원본 캐시를 재생성하는 public loader를 호출하지 않고 보관본을 읽는다. 원 projection이 원 producer/정책 세대와 맞는지 먼저 확인한다.

- 삼성전자와 나머지 종목을 분리하고, 각 집합에서 ENTER_NOW/BLOCK/RECHECK 및 source-invalid를 따로 보존한다. 현재 RECHECK 연구의 수치를 전체 행동 집합에 그대로 전용하지 않는다.
- candidate 선택은9/29·9/30에서만 수행한다.10/2 결과를 본 뒤 임계값·날짜·유형·청산방법을 재선정하지 않는다. 실패 후보와 모든 trial을 보존한다.
- 당시 이용 가능했던 입력만 분류에 사용한다. 당일 최종 high/low, 장후 봉, 이후 수급으로 `intraday_range_pct` 등 당시 값을 덮어쓰지 않는다.
- native identity 없는 행도 기술적 가격 분석에는 남긴다. 운영 정책 비교의 native 분모에는 임의 ID를 만들어 추가하지 않는다. 중복 민감도는 **전체 관측에서** 먼저 시간순으로 추린 후 유형을 적용한다.

완료 조건: 날짜/행/원본 hash/판정/비용 대사, 중복·결손·세션 분모 보존, 미래 입력 배제, 비교 조건과 trial 목록 봉인. 전역 계약 결손이면 해당 실험을 중단하고, 식별 가능한 부분 결손이면 그 부분만 제외한다.

### P1 유형이 설명하는 차이 분리

고정 A1 조건과 A의 나머지를 다음 축으로 비교한다.

1. 전체 관측 및 종목 동일 가중 결과.
2. 동일 종목·날짜·venue·session 내 비교. 원천이 허용하면 같은 native watch/기회 내 비교도 별도 출력한다.
3. 같은 비용 구간의 비교와 원래 비용을 낮추지 않는 비용 민감도 검사.
4. 정규장/장전/장후, 시간대, 과거 입력으로 정의한 변동·방향 상태별 기여도. 추가 분할은 설명용이며 후행 최적 셀 선택에 사용하지 않는다.
5. 목표 선도달 비율과 함께 목표/손절/경계 미도달/관측 중단/비용 결손/같은 봉 양쪽 접촉을 모두 표시한다.

체결 용이성60과 변동폭7%의 두 경계를 그대로 둔 2×2 표도 출력해 각 조건과 결합 조건의 기여를 분리한다. 이 표의 다른 셀을10/2 결과로 새 우승 유형에 올리지 않는다.

완료 조건: 개선이 종목 구성, 비용, 반복 관측, 시점 조건 중 어디에 집중되는지 수치로 설명한다. 동일 종목 비교 지원이 없으면 `within_symbol_not_comparable`로 남기며 차이0 또는 효과 부재로 바꾸지 않는다. 원천 전체를 막거나 새 수집 과제로 전환하지 않는다.

### P2 진입을 고정하고 청산 효과 검증

같은 anchor·매수 기준가격·비용·관측 구간에서 다음 **4개 가격 경로 진단**만 비교한다. 실제 live exit 선택과 분리한다.

| 진단 | 종료 규칙 | 고정 요소 |
|---|---|---|
| X0 | 600초 종료 가격 | 선행 연구의 시간 종료 대조군 |
| X1 | 순목표 +0.1% 첫 도달 또는 가격 -0.7% 경계, 미도달이면600초 | 기존 target-first 정의 연결 |
| X2 | 순목표 +0.2% 첫 도달 또는 같은 손절/시간 종료 | 목표 폭 가설 |
| X3 | 순목표 +0.3% 첫 도달 또는 같은 손절/시간 종료 | 목표 폭 가설 |

- 같은 기회에4개 모두 계산 가능한 paired 집합과 전체 적격 집합을 함께 보고한다. 불가 행과 이유를 숨기지 않는다. 미도달이라도 종료 가격이 유효하면 timeout 결과를 계산한다. 종료 가격이 없으면 결손으로 유지한다.
- 매수는 당시 executable ask다. 완료봉 진단은 목표 가격 접촉과 stop 접촉을 CF로 기록한다. 가격 -0.7% stop의 비용 차감 결과는 -0.7%에서 유효 왕복 비용을 뺀 값이며 손절을 순 -0.7%로 바꿔 계산하지 않는다. 세금/수수료/spread 비용을 이중 차감하지 않는다.
- 기존 quote/trade가 있으면 exact route·epoch·시각의 executable bid로 접촉 이후 실제로 팔 수 있었던 가격을 추가 비교한다. 이것도 체결 receipt가 없는 가격 CF다. 호가 없는 경우 봉 고가를 매도 체결가격으로 확정하지 않는다.
- 같은 봉에서 목표와 손절이 모두 닿으면 순서 미확정으로 남긴다. 최초 부분 봉의 판단 이전 가격을 포함할 수 있는 시간 계약을 확인하고, 구분 불가 부분은 제외 민감도/범위로 제시한다.
- 목표 도달 후600초까지 되밀림, 목표 도달시간, 목표 전 adverse, timeout 손익, 보유시간을 출력한다. 성공률은 각 종료 계약의 **비용 차감 양수 종료 / 비교 가능한 종료**로 계산하고, 기존 target/(target+stop) 비율을 함께 표시하되 혼용하지 않는다.

학습에서 X0 대비 개선 순위1개를 고정한다. 비용 차감 성공률 개선을 먼저 비교하고, 기존 승자 보존율은 설명 지표로만 출력한다. 단순10분 종료의 음수 평균을 곧바로 entry 후보 탈락 조건으로 추가하지 않는다. 순손익·최악 손실·기회 수·결손은 함께 공개하고 실제 운영 승격은 해당 family 계약에 따라 별도로 판정한다. 현재 실제 exit가 재생 가능하면 원 parent를 별도 대조군으로 추가하며 X0를 실제 정책이라고 부르지 않는다.

완료 조건: 같은 진입에서 청산 규칙이 성과 차이를 만들었는지, 어떤 원천 수준에서 성립하는지 명시한다.10/2에서 선택 가설이 실패하면 `not_replicated`로 끝내고2위 청산으로 바꾸지 않는다.

### P3 청산을 고정하고 진입 시점 검증

P2에서 선행 날짜에 고정한 종료 계약을 사용한다. 선행에서 선택되지 않으면 진입 시점 진단에는 X1을 사전 고정 대조 계약으로 사용하고, 결합 정책의 개선은 미입증으로 표시한다.

- A1이 처음 관측된 시점과 **같은 원 native 기회·route에서 원천이 유효한 다음 확인 시점**을 비교한다. 최대300초 안의 첫 적격 확인만 사용하고, 이후 좋은 결과/싼 가격/완전한 비용을 찾아 다시 선택하지 않는다.
- native가 없는 관측은 같은 날짜·종목·venue·session·route·bundle 및 원 capture의 시간 연속성을 확인해 **비승격용 관측 쌍**으로 별도 분석할 수 있다. 알려진 native 변경, transport epoch 변경, 원천 단절을 가로질러 연결하지 않는다. 이 결과를 새 native 기회로 만들거나 P5의 정식 정책 지원수에 더하지 않는다. native 결손만으로 가능한 가격 연구까지 일괄 중단하지 않는다.
- 확인 조건의 목록과 허용 soft reason은 P0에서 실제 source/현재 판정 owner를 읽어 고정한다. 현재 `hard`/source 차단이 남은 관측은 진입 가능 집합에 넣지 않는다.
- 고정 종료시각과 최대 양쪽 원천 비용을 사용한 순수 가격 타이밍 효과, 각 진입 후 동일 보유기간 효과를 분리한다. 지연으로 짧아진 관측구간을 완전한600초 결과로 취급하지 않는다.
- 후속 관측 없음, 확인 없음, 다른 native 기회로 넘어감, 원천/비용 결손을 서로 분리한다. 그 행들의 성과를0 또는 손실로 채우지 않는다.

완료 조건: 동일 사건에서 진입가 개선·상승 확인·추격 비용 중 무엇이 달라졌는지 설명하고, 타입 선택과 진입 시점 선택의 효과를 분리한다. 지원이 없는 축은 해당 가설만 `not_observed`로 종료한다.

### P4 삼성전자 BLOCK 이후 회복 연구

P0 원천 봉인 뒤 P1~P3와 분리된 삼성전자 결과를 만든다. 분석 대상은 목표 선도달19건만 고르는 집합이 아니라 **BLOCK186건 전체**와 같은 날짜의 삼성전자 RECHECK/ENTER 비교 관측이다.

1. `large_sell_print_present`가 발행·유지·해소되는 당시 tick/window/TTL·route 계보를 재구성한다. 사후 상승은 해소 조건으로 쓰지 않는다.
2. 원래 차단 판단은 보존하고, 첫 후속 관측에서 대량 매도 신호가 사라진 뒤 매수 흐름/가격 회복이 확인되는 가설을 소수로 고정한다. hard/source 조건을 우회하는 가설은 실행 후보와 분리된 진단으로만 기록한다.
3. 9/29·9/30에서 조건을 고정하고10/2의 세 목표 사례 및 다섯 손절 사례를 포함한 전체 집합에 적용한다. 세 성공 사례에만 맞춘 조건을 새 검증이라고 하지 않는다.
4. 원래 비용, 최소0.33%·0.43% 비용, 반복 관측 축소를 비교한다. 당시 원천이 실제 경과한 뒤에도 낡은 sell flag가 남은 재현 가능한 결함이 발견되면 producer 수리 계획을 별도로 작성한다. 단순 상승 사실로 flag를 삭제하지 않는다.

완료 조건: 차단 이후 가격 회복은 있었는지, 당시 확인할 신호가 있었는지, 확인 후 진입이 비용을 넘었는지 각각 답한다. 원차단의 적절성, source 결함, 새 패턴 가설을 분리한다.

### P5 실제 parent 대비 정책 후보 재생과 종료 판단

위 가격 연구에서 남은 가설만 당시/current 연구 parent hash와 결속해 기존 generator 또는 pure evaluator로 격리 재생한다. 당시 정책을 재현한 결과와 새로운 parent 아래 재계산 결과를 구분한다.

- `incumbent -> candidate`의 ENTER/BLOCK/RECHECK 전이, 기존 진입 제외, 새 진입 포함, 판정 변화 없음을 전부 출력한다. **A전체58.29%는 기존 운영 정책 승률 대조군이 아니다.**
- source/quote/account/broker/quantity/cooldown/owner 및 hard/protect/emergency guard를 보존한다. 보조 AI가 기계 non-entry를 승격하게 만들지 않는다. 새 진입에 정확한 보조 응답이 없으면 기계 결과와 결합 결과를 나누고 결합은 미관측으로 남긴다.
- 동일 source/비용/원 native 기회/종료 계약에서 기존 정책보다 높은 비용 차감 성공률을 우선 평가한다. 기존 성공100%/80% 보존 조건을 생성기·후처리·validator에 다시 도입하지 않는다. 전체 비교 가능성, 기존 family의 표본/날짜 계약, 위험 계약은 별도 결과로 공개한다.
- 모든 날짜를 이미 사용했다는 한계 때문에 이번 결과는 역사적 연구 후보와 구현 필요성까지 판단한다. 독립 검증이 필요한 운영 계약을 이 계획만으로 충족시킨 것으로 선언하지 않는다.

종료 상태는 `research_candidate`(명시된 계약의 개선 가설), `not_replicated`(후단 비교 불재현), `hold_sample`(지원 부족), `source_gap`(특정 입력 결손), `no_effect`(충분한 비교에서 행동/결과 차이 없음)로 구분한다. 한 가설의 실패를 모든 가설 소진으로 확대하지 않는다. 고정 목록을 소진하거나 연구 후보가 확보되면 이번 실험군을 종료하고 결과와 다음 결정 근거를 기록한다.
