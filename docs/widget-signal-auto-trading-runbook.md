# Widget retirement

위젯 자동·수동 매매, UI/API, 수집·알림·연구·정책 발행·장후 stage와 설치 경로는 영구 퇴역한다. 과거 실행 명령은 현행 runbook에 제공하지 않는다.

[제거계획](proposals/widget-full-runtime-postclose-retirement-plan-2026-10-06.md)과 당일 체크리스트의 `WidgetFullRetirement1006`이 실행 gate를 소유한다. 공통 비용·WS·원천은 Main/에피소드가 소유하며 주문/custody 원본은 감사 이력으로 보존한다. rollback도 위젯 신규 BUY·timer를 복원할 수 없다.

원본 운영 문서는 Git 이력과 hash-bound `tmp/widget-retirement-execution-20261006/operating-docs-before.tar.gz`에 보존한다. Windows 설치본은 운영자가 직접 제거 예정이며 확인 전까지 외부 경계는 대기다.
