# 보유 AI 프롬프트·입력·해시·주기 재점검 — 2026-09-25

## 결정

[호출 점검 계획](../proposals/holding-ai-prompt-input-hash-cadence-audit-plan-2026-09-25.md)의 정적·합성 코드 계약을 재검토해 결함 3건을 수정했다. **전체 계획 완료와 조건부 배포 승인은 아직 선언하지 않는다.** v10 자연 투표 원장과 실제 공급자 응답·지연 표본이 없고, 첫 트레일링 신호 직전 동기 호출 가능성도 남아 있다. 실제 모델 정확도, 시장·경로별 신호 전 정족수 성숙률, timeout율, 다른 AI의 공유 예산 영향 및 비용 후 경제성은 미측정이다. 이 보고서는 주문·임계치·호출 주기·provider·봇 상태의 변경 권한이 아니다.

## 테스트 데이터·성능

- 합성 경로/시장·입력 결손·투표 결과·동시 선점 회귀를 포함한 대상 pytest **1,216건 통과**. Python 컴파일, `git diff --check`, 문서 출력 전용 파서 **26건** 통과. 변경된 손절 후보 생략 fixture도 포함한다.
- 임시 파일에 600개 상이한 path 입력을 선점하면서 전 이력 조회+claim fsync를 측정했다: p50 **3.816ms**, p95 **4.839ms**, p99 **4.959ms**, 최대 **7.396ms**, 파일 **99,600 bytes**. 이는 원천 REST/WS, prompt 직렬화 전체, 공급자 왕복, 원장 표 저장을 포함하지 않는다.
- 실제 9/23 `ai_decision_trace`의 마지막 2MB/92행을 제한적으로 읽어 `holding_score_v2` 72행을 확인했다. v10 판단 입력·출력 동결 세트가 아니므로 성능·정확도 모수로 사용하지 않았다. 111MB 전체 원천을 재처리하지 않았다.
- 자연 `data/runtime/holding_path_votes` 디렉터리는 없다. 작업 셸의 `OPENAI_API_KEY`/`OPENAI_API_KEYS`도 없다. 운영 계정의 키 존재 여부와 실제 PID의 모델 요청은 이 결과로 단정하지 않는다.

## 배포 경계와 다음 닫힘 조건

현재 selector는 `6060f5d0424193cdf747248224af1f9aac2ee90a`이며 메인 PID 영수증은 없다. release-set 읽기 검사는 통과했으나 9/25 controller·tuning wrapper가 해당 release에서 대기 중이고 선행 `threshold_cycle_postclose`는 실패 상태다. [릴리스 라우팅](../runtime-release-routing.md)은 실행 중 wrapper와 selector 전환을 금지한다. 9/25 실행 checklist도 없다. 이 소스 수정은 아직 immutable release/PID에 반영되지 않았다.

1. 트레일링 첫 신호 시점에 원천 조회와 모델 호출을 기다리지 않도록 호출 위치·비동기 수집의 동시성/안전 계약을 닫고, 신호 시점 동기 호출 0건 회귀를 만든다.
2. 세 시장×다섯 경로의 결손/정상 동결 입력에 대한 실제 v10 응답을 수집해 모델 ID, 경로별 출력 유효율·판단 결과, 단계별 p50/p95/p99, 7초 timeout·늦은 응답·공유 예산 영향을 측정한다. 자연 자료가 없으면 경제성은 `null/source_gap`이다.
3. 위 코드·성능·결과 결함이 닫힌 뒤 정식 release 검토를 완료하고, 그 시점의 wrapper·checklist·selector를 다시 대사해 사용자가 이미 승인한 조건부 배포를 수행한다. 새 PID 소비와 자연 투표·체결 경제성은 별도 영수증으로 확인한다.
