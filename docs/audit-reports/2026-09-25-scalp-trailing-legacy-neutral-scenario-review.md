# 익절 4축 과거자료 중립 추정 재생·코드리뷰

기준: 2026-09-25 KST, clean baseline 2026-06-05 이후. 이 산출물은 `historical_scenario_diagnostic_only`다. 기존 엄격 완료·체결 비용 모수와 독립적이며, 수치가 실현 비용 후 EV·실제 후보 체결·임계치 변경 승인을 뜻하지 않는다.

## 추정 계약

- 일별 완료 projection을 누적하되 `COMPLETED`·메인 스캘핑·유효 `profit_rate`를 요구한다. 매수·매도가, 보고된 수량, 매도시각이 있으면 **추정 시뮬레이션**에 넣는다. 매수·매도 체결 leg와 정확 비용이 없는 행은 엄격 4축 재생에 계속 넣지 않는다.
- 과거 `mfe_pct`가 있으면 현재 비용 모형으로 가격 최고점을 역산한다. 보고된 매도가의 순수익보다 MFE가 낮으면 원천 충돌로 중립 처리한다. MFE가 없어도 청산 규칙이 추정 `scalp_trailing_take_profit`이면 현행 약·강 되돌림폭 각각에서 기록 매도가에 도달한 **가상 최고점**을 만든다. 이는 과거 실제 arm·first crossing 시각이 아니다.
- 최고점도 규칙도 없으면 후보의 변화량을 중립 0으로 둔다. `neutral_unknown_effect_ids`를 반드시 함께 낸다. AI 점수 경로가 없으므로 점수 경계 변화는 중립이며 약·강 두 가정의 결과를 별도로 낸다. 경로는 `진입→가상 최고점→기록 매도가`이고 호가잔량·체결 성공을 재현하지 않는다.
- 후보와 가상 현행값의 가격 차이를 보고된 유효 수익률에 더한다. 설정 비용률과 추가 슬리피지 0/30/100bp를 별도 가정으로 적용한다. 결손 비용을 0원이나 정확 비용으로 표시하지 않는다. 모든 시장에서 단일축·최대 81개 제한 복합 조합을 계산하고, 완료일 기준 최근 날짜 검증 구간을 표시한다. 출력에는 `research_candidate=null`, `runtime_selected=null`을 고정했다.
- `input_projection_sha256=f46bf0757430fff3f89167c0d333bdc09c352693a395f468bbdfbb9029e361e0`. 329행의 과거 완료 projection을 이용한 읽기 전용 계산이다. 기존 Kiwoom API 요청·parser와 실주문 경로는 변경하지 않았다.

## 기존 구현 결함 수정과 수용 경계

- 누적 보고서는 6/5부터 모든 달력 날짜의 스냅샷 누락을 전체 결손으로 세었다. 장이 닫힌 주말에 파일이 없으면 누락으로 세지 않도록 고쳤고, 저장된 주말 파일은 그대로 검사한다. 9/25 원천의 결손은 구형 미봉인 62일과 주중 스냅샷 누락 20일로 남아 있다. 이 결손 때문에 엄격 모수의 전체 census와 실제 정책 선택은 계속 보류다.
- 시작값·4축 연구의 최신 검증 구간을 진입일보다 **완료 관측일**에 우선 결합했다. 4축은 최종 SELL fill 날짜와 완료일이 다르면 그 ID를 원천 결손으로 격리한다. 날짜를 알 수 없는 구형 테스트 입력의 진입일 fallback은 별도 ID로 공개한다.
- 첫 회귀에서 주말 누락을 기대하던 구 테스트가 실패해 새 계약에 맞게 수정했다. 재리뷰에서 MFE 2건의 가격 충돌, 후보와 현행의 같은 가상 매도가에 슬리피지를 중복 부과할 위험, 완료일·SELL 체결일 불일치, 중복 ID의 이중 집계 위험을 찾아 각각 중립·0효과·원천 격리로 보완했다.
- 남은 한계는 시점별 AI·호가잔량·first crossing 부재, 추정 청산 규칙, 설정 비용/슬리피지 가정, 기존 일별 완료 census 미봉인이다. 진단 결과를 엄격 `trailing_four_axis_market_tuning`이나 bootstrap 선택 영수증에 연결하지 않았다.
